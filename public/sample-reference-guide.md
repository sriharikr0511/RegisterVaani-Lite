# Sample Visit Register Guide

This is an example reference document for RegisterVaani Lite. Upload it from the Knowledge base page, then rebuild the FAISS index so its guidance is searchable.

## Person name

Record the name exactly as it is spoken or written. For another script, transliterate the name into Latin letters while preserving how it sounds. Do not replace a name with a guessed name.

## Village

Record the village only when the visit note names it. A nearby town, district, or worker's location is not automatically the village. If the village is not stated, leave the field blank and ask the field worker.

## Age and weight

Enter age in years and weight in kilograms only when the note gives a clear number and unit. If a value was not measured or recorded, leave it blank. Never estimate age or weight from appearance or other details.

## Visit and follow-up dates

Use an exact calendar date when the note provides one. A phrase such as “next Monday” is not an exact date unless the field worker confirms which date they mean. Keep the follow-up status separate from the follow-up date.

## Evidence and translation

For each suggested value, keep a short quote from the original visit note as evidence. Translate descriptive notes into clear English, but keep names and place names as transliterations. If the evidence does not support a value, leave it blank.

## Human review

All extracted fields are suggestions. The field worker must review the original note, correct mistakes, resolve required details, and explicitly approve the record before it is treated as final.
